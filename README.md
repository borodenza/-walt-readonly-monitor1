# Walt — стратегии A + Mira B

**Система мониторинга запущена в GitHub Actions в режиме READ ONLY. Реальные ордера НЕ выполняются.**

## Как открыть интерфейс

1. [Откройте Actions](https://github.com/borodenza/-walt-readonly-monitor1/actions).
2. Выберите последний запуск **Walt read-only BTC ETH monitor**.
3. Внизу страницы найдите **Artifacts → walt-system-...** и скачайте ZIP.
4. Распакуйте ZIP. Откройте **walt-system.html** (единый центр A/B) или **mira-recovery.html** (карточки стратегии B и локальные кнопки). Это снимок, а не живой сайт.

## Что внутри

- **A / Trend Following:** BTC/ETH; 5m/15m/1h; EMA20/50, RSI14, ATR14 и объёмы. Бюджет 9 USDT, риск ≤0.09 USDT, чистый RR ≥2, 1×, до 2 сделок/сутки. Только технические кандидаты, без торговых ордеров.
- **B / Mira Recovery:** 8 рынков; восстановление после падения, не более 3 исследовательских предложений в сутки; бюджет 9 USDT, риск ≤0.18 USDT, 1×. Кнопки подтверждения/отклонения НЕ размещают сделку и требуют отдельного предпросмотра Walt.
- **walt_guard.py:** расчёты стресс-сценариев размера, комиссии, проскальзывания, стопа, тейка и фандинга; не разрешает сделки автоматически.
- **walt_status.py:** генерирует `walt-system.json` и `walt-system.html` и закрывает любую торговлю, если неизвестен критический параметр.

Работает cron GitHub с запрошенным интервалом ~15 минут (фактическая периодичность не гарантирована) и отдельная **почасовая** автоматизация ChatGPT для проверки подтверждённых кандидатов. В репозитории нет ключей Walt или средств исполнения ордеров.

[Полная спецификация и риски](SYSTEM.md)

**Перед реальной торговлей нужно подтвердить USDC, способ автономного исполнения через Walt и возможность соблюдения риска при минимальных объёмах и 1% стресс-проскальзывании.** Эти условия пока не выполнены.
